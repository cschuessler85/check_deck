# Bedienungsanleitung (Click-to-Click)

## Ablauf: cashier-qr-scan
*Modul: `live_app.admin`*

### Schritt-für-Schritt-Anleitung
- **Schritt:** 1 Kassenpersonal startet den QR-Scanner. → **Ergebnis:** Der Bezahlvorgang kann direkt aus einem Scan heraus fortgesetzt werden.
- **Schritt:** 2 Ein erkannter Code wird normalisiert, gesucht und bei gueltigem Treffer in den Zahlungsdialog uebernommen.
